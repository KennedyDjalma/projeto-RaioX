# Projeto Raio-X

Este projeto tem como objetivo disponibilizar uma página interativa para cálculo de parâmetros.  
A aplicação funciona de forma simples: o usuário insere os dados necessários e o sistema realiza os cálculos automaticamente, exibindo os resultados de maneira clara e organizada.
